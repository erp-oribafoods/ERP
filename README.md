# ORIBA ERP

Plateforme de gestion commerciale et force de vente d’Oriba Foods.

Adresse : https://erp-oribafoods.github.io/ERP/

Ce dépôt contient uniquement la version publiée de l’interface. Le code source est dans le dépôt ERP-ORIBA-FOODS2 (branche erp-gestion-commerciale).

## ERP RH (SECOP & FOOD)

Adresse : https://erp-oribafoods.github.io/ERP/rh/

Gestion administrative du personnel selon la procédure RH-01 (dossiers, congés, variables de paie, HSE, matériel, tâches inter-services, rapports DG). Comptes propres à l'ERP RH, gérés par le Responsable RH. Serveur : fonction Supabase `rh-api`, données dans le schéma `rh`.
